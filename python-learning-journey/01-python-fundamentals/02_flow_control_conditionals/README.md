**Source:** Video tutorial + Book Ch.2 (if-else and Flow Control)

## Concepts covered
- `if`, `elif`, `else` statements
- Comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`)
- Logical operators (`and`, `or`, `not`)
- Nested conditionals
- Truthy/falsy values in Python
- Ternary (conditional) expressions

## My Notes
Conditions in Python don't need parentheses like some other languages — just a colon
and an indented block. `elif` avoids writing nested if-statements for multiple checks.
`and`/`or` let you combine conditions instead of nesting if-statements inside each other.
