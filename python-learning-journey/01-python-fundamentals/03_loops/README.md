## My Notes
`while` loops run as long as a condition stays true — good when you don't know how many
times you'll loop in advance (like a guessing game). `for` loops are better when you're
looping a fixed number of times or going through a known sequence. `break` exits a loop
immediately; `continue` skips to the next iteration without exiting.
