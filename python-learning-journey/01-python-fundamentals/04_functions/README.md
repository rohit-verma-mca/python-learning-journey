## My Notes
A function that uses `return` gives back a value you can store or reuse elsewhere in
your code — `print` just displays something and gives nothing back. Variables created
inside a function only exist inside it (local scope), unless you explicitly use `global`.
Default argument values let you call a function without providing every argument.
