# 04 — Mini Projects

Small projects that combine multiple concepts once enough topics are covered. Each project
gets its own folder with its own README (what it does, how to run it, a screenshot/GIF if
it's visual).

These are the folders worth linking directly in your GitHub profile README and LinkedIn
Featured section once they exist — recruiters look at running code before they look at
tutorial exercises.

## Ideas to build here
- An automation script that solves a real annoyance (bulk file rename/organize, PDF merger)
- A small OOP-based CLI app (contact book, expense tracker, quiz game)
- A web scraper for a genuinely useful, small use case
- An Excel/CSV report generator
- The three video-tutorial capstone projects (automation script, a small ML demo, a basic
  Django site) once you reach that material
